# Safe Paths — Confirmed Deletable

These paths are safe to delete. macOS or the relevant app regenerates them automatically.

## Always Safe (LOW risk)

| Path | What it is | Regenerated by |
|------|-----------|----------------|
| `~/Library/Caches/*` | Per-app cache files | Each app on next launch |
| `/Library/Caches/*` | System-wide app caches | macOS / apps |
| `~/Library/Logs/*` | App log files | Apps on next run |
| `/Library/Logs/*` | System log files | macOS |
| `~/Library/Saved Application State/*` | Window restore state | Apps on next open |
| `~/Library/Application Support/CrashReporter/*` | Crash reports | System on next crash |
| `/private/tmp/*` | Temporary files | macOS on reboot |
| `~/.Trash/*` | Deleted files | User action |
| `~/Library/Developer/Xcode/DerivedData/*` | Build artifacts | Xcode on next build |
| `~/Library/Caches/com.apple.dt.Xcode/*` | Xcode caches | Xcode |
| `~/Library/Caches/Homebrew/*` | Downloaded bottle cache | `brew install` |
| `~/.npm/*` | npm download cache | `npm install` |
| `~/.pnpm-store/*` (dangling) | pnpm content store | `pnpm install` (pruned only) |
| `~/.yarn/cache/*` | Yarn package cache | `yarn install` |
| `~/Library/Caches/pip/*` | pip download cache | `pip install` |
| `~/.gradle/caches/*` | Gradle build cache | Gradle build |
| `~/.pub-cache/*` | Dart/Flutter pub cache | `pub get` / `flutter pub get` |
| `~/.cocoapods/repos/*` | CocoaPods specs repo | `pod install` |
| `~/go/pkg/*` | Go module download cache | `go build` / `go mod download` |
| `~/.npm/_npx/*` | npx one-time runner caches | `npx <cmd>` re-downloads |
| `~/.vscode/extensions/<old-versions>` | Duplicate VS Code extensions | VS Code keeps newest |

## Conditionally Safe (MEDIUM risk — confirm first)

| Path | What it is | Caveat |
|------|-----------|--------|
| `~/Library/Developer/CoreSimulator/Devices/*` | iOS Simulators | Re-download from Xcode takes time + bandwidth |
| Docker stopped containers + dangling images | Unused Docker data | Re-pull required for those images |
| Local `node_modules/` directories | Installed packages | `npm install` in each project to restore |
| `~/.rustup/*` (if `rustc` not in PATH) | Stale Rust toolchain | Fully removable if unused |
| `~/.cargo/*` (if `cargo` not in PATH) | Stale Cargo data | Fully removable if unused |
| `~/.pub-cache/*` (if no flutter/dart) | Stale Flutter/Dart cache | Fully removable if unused |
| `~/Library/Application Support/*/vm_bundles` | App VM bundles (e.g. Claude) | App re-downloads on launch |
| `~/Library/Application Support/Code/CachedExtensionVSIXs` | Old VS Code extension downloads | Re-downloaded when needed |
| `~/Library/Application Support/Code/WebStorage` | VS Code cached web content | Regenerated by VS Code |
| `~/.ollama/models/<specific model>` | Ollama AI models | Re-download from Ollama registry |
| Time Machine local snapshots | APFS local recovery points | Needs external TM backup or iCloud confirmed |
