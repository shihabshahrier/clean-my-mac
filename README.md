# clean-my-mac

> AI-assisted safe disk space recovery for macOS developers.

A Claude Code skill that safely recovers disk space on M1/M2/M3 Macs. Every action is
explained, previewed in dry-run mode, and confirmed before execution. Nothing is deleted blindly.

---

## What It Cleans

| Target | Risk | Recovery |
|--------|------|----------|
| User & System Caches | 🟢 Low | Auto-regenerated by macOS |
| Logs & Trash | 🟢 Low | Always regenerated |
| Homebrew cache | 🟢 Low | `brew cleanup` |
| npm / pnpm / yarn caches | 🟢 Low | Package managers rebuild on install |
| Xcode DerivedData | 🟢 Low | Xcode rebuilds on next build |
| iOS Simulators | 🟡 Medium | Re-downloadable from Xcode |
| Docker images | 🟡 Medium | Re-pullable from registry |
| node_modules (listed only) | 🟡 Medium | You choose which to delete |
| Time Machine snapshots | 🟡 Medium | Needs backup confirmation |
| AI model files | 🔴 High | Listed only — you choose |
| Xcode Archives | 🔴 High | Double confirmation required |
| iOS Device Backups | 🔴 High | Guided to Finder only, never auto-deleted |

Typical recovery on a 256 GB M1 Mac:
- Light developer (no Xcode/Docker): **5–15 GB**
- Active developer with Xcode: **20–60 GB**
- Full setup with Docker + Xcode + AI models: **30–100+ GB**

## Installation

### Option 1 — Copy to Claude skills directory (recommended)

```bash
git clone https://github.com/shihabshahrier/clean-my-mac.git
mkdir -p ~/.claude/skills/
cp -r clean-my-mac ~/.claude/skills/clean-my-mac
chmod +x ~/.claude/skills/clean-my-mac/scripts/*.sh
```

### Option 2 — Use from project directory

Clone anywhere and run Claude Code from inside the repo:

```bash
git clone https://github.com/shihabshahrier/clean-my-mac.git
cd clean-my-mac
claude
```

## How It Works

1. **Analysis** — Runs `scripts/analyze_storage.sh`, shows full breakdown with risk levels
2. **You choose** — Claude asks which categories to clean
3. **Dry-run** — For each phase, shows what *would* be deleted before touching anything
4. **Confirmation** — You approve before any deletion happens
5. **Cleanup** — Scripts run, size freed is reported
6. **Report** — Summary saved to `~/clean-my-mac-report-<date>.md`

## Security

- `allowed-tools` in SKILL.md restricts Claude to: `Bash`, `Read`, `Glob`, `Grep`, `Write`
- No network access during cleanup
- `config/protected_paths.txt` is checked before every deletion operation
- Scripts use `set -euo pipefail` — fail fast on errors
- All operations logged to `~/clean-my-mac-log-<date>.txt`
- Every script supports `--dry-run` mode
- HIGH-risk operations require double confirmation
- iOS Device Backups: guided to Finder only, never scripted
